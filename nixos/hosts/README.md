# `nixos/hosts/` — Machine Definitions

## What Goes Here?

Each subdirectory in `nixos/hosts/<hostname>/` defines a complete machine exposed as `flake.nixosConfigurations.<hostname>`.

### Standard 3-File Host Layout
- **`default.nix`**: Registers `flake.nixosConfigurations.<hostname> = inputs.nixpkgs.lib.nixosSystem { ... };`.
- **`configuration.nix`**: Defines `flake.nixosModules.<hostname>Configuration`, importing the desired feature modules (`self.nixosModules.base`, `self.nixosModules.mangowm`, etc.) and setting the machine's `networking.hostName` and bootloader.
- **`hardware.nix`**: Defines `flake.nixosModules.<hostname>Hardware`, wrapping the contents of `/etc/nixos/hardware-configuration.nix` generated by `nixos-generate-config`.

## Current Hosts
- **[`vm/`](./vm/)**: QEMU/KVM virtual machine using GRUB (`/dev/vda`), MangoWM + Noctalia Shell, and `vscode-server`. Build with `#vm`.
- **[`laptop/`](./laptop/)**: Physical laptop using UEFI (`systemd-boot`), MangoWM + Noctalia Shell, laptop power/Bluetooth/backlight services, and Nvidia drivers. Build with `#laptop`.

---

## How to Add a New Host

1. Create a folder `nixos/hosts/<new-host>/`.
2. Add `default.nix`, `configuration.nix`, and `hardware.nix` following the pattern in [`nixos/hosts/laptop/`](./laptop/).
3. Because `flake.nix` uses the Dendritic auto-import pattern, the new host is immediately available as `.#<new-host>` without editing `flake.nix`.
